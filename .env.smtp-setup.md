# 📧 SMTP Configuration Guide for Railway Deployment
# ═════════════════════════════════════════════════════════════════════════════
# 
# CRITICAL FOR PRODUCTION: Email features (password reset, verification) require
# proper SMTP configuration. Without it, users cannot reset passwords or verify emails.
#
# ═════════════════════════════════════════════════════════════════════════════

# 🔴 DO NOT USE PLACEHOLDER VALUES (your-email@gmail.com, your-app-password)
#    These are examples only. Replace with real credentials.

# ═════════════════════════════════════════════════════════════════════════════
# STEP 1: Choose Your Email Provider
# ═════════════════════════════════════════════════════════════════════════════

# ✅ OPTION A: Gmail (Free, Recommended for Small Projects)
#
#    1. Enable 2-Factor Authentication: https://myaccount.google.com/security
#    2. Generate App Password: https://myaccount.google.com/apppasswords
#    3. Select "Mail" and "Windows Computer"
#    4. Copy the 16-character password (remove spaces when pasting)
#
#    Then use these settings:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=your-actual-email@gmail.com
SMTP_PASSWORD=xxxx-xxxx-xxxx-xxxx

# ---

# ✅ OPTION B: SendGrid (100 free emails/day, Best for Startups)
#
#    1. Sign up: https://sendgrid.com
#    2. Create API Key: Settings → API Keys → Create API Key
#    3. Copy the key (starts with "SG.")
#
#    Then use these settings:
# SMTP_HOST=smtp.sendgrid.net
# SMTP_PORT=587
# SMTP_USER=apikey
# SMTP_PASSWORD=SG.your-actual-api-key-here

# ---

# ✅ OPTION C: Brevo (300 free emails/day, Good Balance)
#
#    1. Sign up: https://www.brevo.com
#    2. Get SMTP credentials: Settings → SMTP & API
#
#    Then use these settings:
# SMTP_HOST=smtp-relay.brevo.com
# SMTP_PORT=587
# SMTP_USER=your-email@yourdomain.com
# SMTP_PASSWORD=your-brevo-smtp-password

# ---

# ✅ OPTION D: Mailgun (Custom domain, Professional)
#
#    1. Sign up: https://mailgun.com
#    2. Get SMTP credentials: Sending → SMTP
#
#    Then use these settings:
# SMTP_HOST=smtp.mailgun.org
# SMTP_PORT=587
# SMTP_USER=postmaster@sandboxXXXX.mailgun.org
# SMTP_PASSWORD=your-mailgun-password

# ═════════════════════════════════════════════════════════════════════════════
# STEP 2: Deploy to Railway
# ═════════════════════════════════════════════════════════════════════════════
#
# 1. Copy the SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD values
# 2. Go to Railway Dashboard → Your Deployment
# 3. Click "Variables" tab
# 4. Add the 4 SMTP variables:
#    - SMTP_HOST
#    - SMTP_PORT (as string: "465" or "587")
#    - SMTP_USER
#    - SMTP_PASSWORD
# 5. Railway will auto-redeploy
# 6. Test by attempting password reset
#
# ═════════════════════════════════════════════════════════════════════════════
# STEP 3: Test Your Configuration
# ═════════════════════════════════════════════════════════════════════════════
#
# Run locally to verify before deploying:
#   npm run test-smtp
#
# Or test manually:
#   node test-smtp.js smtp.gmail.com 465 your-email@gmail.com your-app-password
#
# ═════════════════════════════════════════════════════════════════════════════
# TROUBLESHOOTING
# ═════════════════════════════════════════════════════════════════════════════
#
# Problem: "SMTP_NOT_CONFIGURED or using placeholder values"
#   → Solution: Set proper SMTP variables on Railway
#
# Problem: "Authentication failed"
#   → For Gmail: Use App Password, not regular password
#   → Check credentials are spelled exactly right
#   → Check no spaces in password
#
# Problem: "Connection timeout"
#   → Try port 465 (SSL) instead of 587 (TLS)
#   → Try a different provider (Gmail → SendGrid)
#   → Check Railway network/firewall settings
#
# Problem: "ENOTFOUND - SMTP host not found"
#   → Check SMTP_HOST spelling (e.g., smtp.gmail.com, not mail.gmail.com)
#   → Make sure not using localhost (won't work on Railway)
